## Deskripsi
Toko Buku Lontar Denpasar merupakan website katalog buku
yang dibuat menggunakan PHP dan Tailwind CSS.

Website menampilkan daftar buku, harga, diskon, status
stok, ringkasan nilai stok, serta nota pesanan pelanggan.

## Fitur
- Menampilkan 8 produk buku
- Menghitung harga setelah diskon
- Menampilkan status stok produk (Tersedia, Sisa n, Habis)
- Menghitung nilai seluruh stok
- Menghitung total belanja dan diskon tambahan
- Menampilkan nota pesanan
- Tampilan responsif

## Teknologi
- PHP 8+
- HTML
- Tailwind CSS
- XAMPP

## Cara Menjalankan
1. Simpan folder praktikum3 di htdocs.
2. Jalankan Apache melalui XAMPP.
3. Buka http://localhost/praktikum3/.
